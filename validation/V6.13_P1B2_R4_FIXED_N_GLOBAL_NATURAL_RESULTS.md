# V6.13-P1B2-R4 — Global FIXED_N natural termination

Base: `5d35b62` (R3 report). Code change **not committed** (as ordered). Scope: **Global of the FIXED_N deep path only.** Repair, Exact, Rescue, OPEN probes, the work-budgeted final Global, B3 and the lower bound are untouched.

## 1. Governor change

* `global_rescue(..., watchdog_cpu_segundos=None)` (new kwarg, default `None` = behaviour of always). When set: `reloj = RelojTrabajoConWatchdog(process_time() + W)` (counts expansions, same convention as `presupuesto_expansiones`) and `limite_tiempo = SIN_TOPE`; the 180 s `deadline` is ignored. The existing depth/restart checks therefore never cut, and the stage ends by its own conditions (`completo` / `estancado`, per restart; the 3-restart multi-start is unchanged).
* Watchdog = **safety only**, `FIXED_N_DEEP_GLOBAL_WATCHDOG_SECONDS = 1800.0` CPU (≈ 18× the natural Global CPU of BK52). If it fires: `stats["motivo_stop"] = "watchdog"`, `stats["presupuesto"]["watchdog_disparado"] = True`, `metadata["fixed_n_deep_governor"]["watchdog_triggered"] = True`, `watchdog_stages` includes `"global"`, WARNING logged; the gates treat it as FAIL/STOP. It is never returned silently as an equivalent result. Mutually exclusive with `presupuesto_expansiones` (`ValueError`).
* Wiring (`_empacar_n_pallets`): when `gobernador_profundo` is active (only the deep call of `armar_pallets_bloques` without `exact_n_incumbent`, and only if no `presupuesto_*` kwarg is present), Global receives `watchdog_cpu_segundos=1800.0` instead of relying on the 180 s deadline. Metadata: `fixed_n_deep_governor` now has `etapas.global = {trabajo (expansiones), unidad, estados_generados, stop_reason, watchdog_triggered, watchdog_cpu_segundos, structural_bound_observed}` and `modo = "rescue_global_terminacion_natural"`.
* **No structural work cap.** `224 · demanda_cajas` is recorded **only as telemetry** (`structural_bound_observed`); no code path compares against it. A test asserts that the only `limite_tiempo` of the mode is `SIN_TOPE`.
* Not changed: search order, beam widths, MRV, candidates, scoring, pruning, expansions, P1-A (not applied to Global). Work and results must be identical to R2/R3; this step isolates the governor.

Diff: `src/global_rescue.py` (+31 −2), `src/packing_bloques.py` (+32 −2, constant + wiring + metadata + comments), `tests/test_p1b2r1_rescue_natural_exhaustion.py` (one test updated for the intentional contract change), new `tests/test_p1b2r4_global_natural_termination.py` (15 tests).

* `gobernador_profundo` is computed only on the deep call and is `False` whenever any `presupuesto_*` kwarg is present, so OPEN probes (`presupuesto_rescue/repair/exact`) and the work-budgeted final materialization (`presupuesto_global_expansiones`) never receive the watchdog: test 13 asserts their Global kwargs are exactly what they were (deadline, or `presupuesto_expansiones` only).
* `_empacar_optimizado` (OPEN) never passes `gobernador_profundo` (R1 test, still green).
