**Anomaly (performance only, output unchanged).** The open path is 59 % slower in wall time in RC2, entirely in SJ87 (+476 s) and SJ97 (+373 s); the other 7 CDs are within +-5 %. ## 6. Known Technical Debt (not failures)

1. **BK52/BK53 deep cascade is still expensive** (golden runs 600–920 s wall each, 560–830 s CPU).
2. **Deep-path CPU-time deadlines still exist** (Rescue/Repair/Exact/Global on the `Pallets_Objetivo` path are still CPU-time governed).
3. **Weight data contract deferred** (`DEFERRED_BUSINESS_DATA_VALIDATION`): weight is reported as `WEIGHT_DATA_UNVALIDATED`, never used for verdicts or decisions.
4. **Real P2/P3/P4 pallets are not reproduced exactly inside the pallet**: for BK35, 3 of 6 real operation pallets are not found by the solver's geometry (24/10/2 residual boxes); the solver closes the CD with its own partition (729/729, N=6).
5. **Performance optimization deferred to V6.13**: BK35 fallback (~465 s; DFS 30 001 nodes + LNS), fixed greedy (25–35 s in BK31/46/49/50), the open-path extra N probes caused by the lower bound without weight (SJ87 +476 s, SJ97 +373 s), and the BK52/BK53 cascade.
6. **No-reserve fallback calibration**: the 100-iteration LNS cap is 1.6x the maximum success observed in a 52-case local census (42 activations: 18 successes, 24 failures; successes complete within 63 LNS iterations / 184 187 reconstruction nodes). It is a local-census calibration, not a proof; it only cuts work and cannot change an already complete solution.
7. **Harness run-directory collision (fixed in the harness, no solver impact)**: with `588d01b` the run directory derived from the second of launch, case id and input hash, so several CDs of the same case launched in the same second overwrote each other's `run.json` (hit once during this validation; the Pilot 1 evidence was re-run with one output directory per CD). `b5dbe40` (branch `pilot/v6.12-rc2`) makes `run_id` unique with microsecond timestamp, case id, CD label, input hash and pid, and creates the directory with `exist_ok=False`.
8. Inherited from RC1 and unchanged: removed FINAL Repair, `LONG_RESCUE_SUCCESS_CLASS_EXISTS`, PROBE Global time-governed drift, CP-SAT operational watchdog, FINAL Global 9500 calibrated from BK52/BK53, BK43 rebaseline (pre-D5 hashes `PRE_D5_REFERENCE_ONLY`).
